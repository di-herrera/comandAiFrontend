# Contexto de produto

A ComandIA não pretende competir inicialmente como sistema completo de restaurante.

Ela é uma camada inteligente que transforma conversas do WhatsApp em pedidos organizados, validados e prontos para execução.

## O frontend administrativo existe para

- Cadastrar empresas.
- Cadastrar unidades.
- Cadastrar produtos.
- Cadastrar ingredientes.
- Cadastrar opções/adicionais.
- Relacionar produtos com ingredientes e opções.

## O frontend administrativo não existe para

- Operar caixa.
- Controlar estoque completo.
- Fechar pagamento.
- Emitir nota.
- Substituir sistema da loja.
- Atender cliente final.

## Frase guia

Do WhatsApp para a comanda, sem confusão.

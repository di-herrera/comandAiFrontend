# Setup local

## Requisitos

- Node.js compatível com a versão do Angular instalada.
- npm.
- Backend `ComandAI.Api` rodando localmente, quando for consumir API real.

## Instalar dependências

```bash
npm install
```

## Rodar frontend

```bash
npm start
```

Abrir:

```text
http://localhost:4200
```

## Build

```bash
npm run build
```

## API local

Por padrão:

```text
http://localhost:5080
```

Configuração:

```text
src/environments/environment.development.ts
```
